Dupont Light Pole App
Corrected publishing package

The old deployment contained only a ZIP file. Netlify needs the extracted website files, not the ZIP inside GitHub.

On your Windows computer

  1. Right-click the downloaded ZIP and select Extract All. Open the extracted folder.
  2. You should immediately see netlify.toml, package.json, and folders named public, private, and netlify.
  3. Open your existing GitHub repository. Choose Add file → Upload files.
  4. Select all the files and folders INSIDE the extracted folder and drag them onto GitHub. Do not upload the ZIP, and do not drag the enclosing folder.
  5. Click Commit changes. At the top level of GitHub, confirm you now see netlify.toml and package.json. The old ZIP may remain; it is not used by the build.
  6. Open your Netlify deploys. Wait for the new deploy to finish. The build should report four functions: app, login, records, daily-backup.
  7. Open the actual site: https://dupontlightpolestreetaddress.netlify.app. Use .netlify.app, not the .netlify.com address in the screenshot.

If Netlify asks for build settings

  • Base directory: leave blank (repository root).
  • Build command: npm run build
  • Publish directory: public
  • Functions directory: netlify/functions

These are already supplied by the root netlify.toml. Never publish the whole repository: only public should be the published directory.

Password and email setup

The opening page is separate from activating sign-in and email. In Netlify → Project configuration → Environment variables, set:

  • APP_PASSWORD: YOUR_APP_PASSWORD
  • SESSION_SECRET: a private, randomly generated value at least 32 characters long. Generate it with a password manager or the command in START_HERE.md. Do not upload it to GitHub.
  • RESEND_API_KEY and BACKUP_FROM: the sending key and verified sender for email backups, as described in START_HERE.md.

Use the Functions scope (or all scopes) and production context, then redeploy. Email setup can wait; the app will show that daily backup email is not yet configured. The recipient remains drguariglia@hotmail.com.

This file is an instruction page, not the app. The app needs a Netlify build for its server-checked password and shared storage. Double-clicking public/index.html locally, or dragging the source ZIP into Netlify Drop, does not install those services.

All 204 poles and the 81-choice street picker are retained. This package does not change your live site until you publish it.
